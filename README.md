Summary of Work Process
During this assignment, I learned how to combine basic HTML form elements with Bootstrap 5 utility classes to create visually appealing and responsive interfaces. The main challenge was integrating the default HTML5 validation with Bootstrap's custom feedback system. I used JavaScript to prevent form submission if the fields are invalid and added a small custom validation script to ensure the "Password" and "Confirm Password" fields match.
